Повтор заказа: API POST /orders/{id}/repeat
Description

Пользовательская история 1

Как покупатель, я хочу повторить прошлый заказ в один клик, чтобы не собирать корзину заново.

Критерии приёмки 2

1. Дано у меня есть доставленный заказ, когда я нажимаю «Повторить», тогда все товары из него попадают в корзину с теми же количествами.
2. Дано в корзине уже есть товары, когда я повторяю заказ, тогда товары добавляются к существующим, ничего не удаляется.
3. Дано части товаров нет в наличии, когда я повторяю заказ, тогда в корзину попадает остальное, а я вижу плашку «2 товара закончились».
4. Дано заказ принадлежит другому пользователю, когда я вызываю API, тогда получаю 404.

Не входит в задачу 3

  • Подбор аналогов для закончившихся товаров — отдельная задача DLV-152.
  • Кнопка в мобильном приложении — DLV-145 (фронтенд).

Материалы 4

  • Макет в Figma: «История заказов — повтор»
  • Контракт API в Confluence: POST /orders/{id}/repeat
