Tool calling: модель просит, приложение выполняет
Пример: пользователь спрашивает статус заказа, а этих данных нет ни в модели, ни в документах
Пользователь
Приложение (бэкенд)
LLM
Функция get_order_status
1«Где мой заказ 1042?»
2вопрос + список инструментов: имя, описание, JSON Schema аргументов
3ответ — не текст, а вызов: get_order_status({"order_id": 1042})
4приложение проверяет аргументы и права и само вызывает функцию
5результат: {"status": "в доставке", "eta": "завтра"}
6результат обратно в модель — сообщением с ролью tool
7«Заказ 1042 в доставке, привезут завтра.»
Главное: модель не выполняет код и не ходит в сеть — она только возвращает JSON с именем функции и аргументами. Вызывает функцию ваш код, поэтому проверка прав и аргументов на нём.
