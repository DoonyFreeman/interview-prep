Агент: LLM в цикле с инструментами
Задача: «Оформи возврат по заказу 1042». Обычный вызов отвечает один раз, агент сам решает, какие шаги сделать

1Обычный вызов

один запрос — один ответ, без действий

запрос
LLM
ответ текстом

«Чтобы оформить возврат, зайдите в личный кабинет…»

2ReAct (Reasoning + Acting)

после каждого результата модель заново решает следующий шаг

Мысль

«нужно найти заказ»

Действие

вызвать find_order(1042)

Наблюдение

результат инструмента

Ответ

когда модель решила, что задача выполнена

3Plan-and-Execute

сначала план целиком, потом выполнение по шагам

Планировщик (LLM)
  1. найти заказ 1042
  2. проверить срок и оплату
  3. создать заявку на возврат
Исполнитель

выполняет шаги один за другим, вызывая инструменты

Шаг не удался?

вернуться к планировщику и перепланировать

Ответ
4Ограничители обязательны: лимит шагов и токенов, таймауты, только безопасные инструменты, подтверждение человеком перед необратимыми действиями (деньги, удаление).
