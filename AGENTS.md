# Interview Prep

## Индекс учебных материалов

Когда добавляешь или меняешь уроки в `content/courses/`, пересобирай индекс
ассистента из той же версии `content/`, которая попадёт на сайт. Для локальной
проверки запусти из корня проекта:

```sh
PYTHONPATH=backend backend/.venv/bin/python scripts/assistant_prepare_index.py
```

Задай вопрос по новому или изменённому материалу и проверь, что поиск возвращает
нужный урок. При выпуске Docker-образ сам собирает индекс вместе с материалами.
См. [руководство ассистента](docs/assistant.md).
