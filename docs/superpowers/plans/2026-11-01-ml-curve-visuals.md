# ROC и PR: пример по отсечкам в шпаргалке

Цель: заменить длинные блоки ROC/PR компактным разбором показанного пользователем примера, с графиками в веб-шпаргалке и трёхстраничном PDF.

1. Взять показанные на скриншоте 9 пар (score, настоящий класс): (0,0), (0,0), (0,1), (0,1), (0.545455,0), (0.849057,1), (0.966292,1), (0.968750,1), (1,1). Значения переписаны с экрана и округлены как на нём. Это не полный набор данных исходного ноутбука.
2. Проверить счётчики для порогов выше 1, 1, 0.84, 0.54 и 0. Равные scores обрабатывать одной группой. Для кривых использовать все уникальные scores. Проверить ROC-AUC, AP и PR-AUC по трапециям точными дробями.
3. Создать нативные векторные графики штатным ReportLab: один источник для SVG на сайте и Drawing в PDF. Добавить поддержку только этих двух изображений в существующий необязательный PDF-генератор. Новые runtime-зависимости приложению не нужны.
4. Сократить только разделы ROC и PR: определения осей, правило score >= t, таблицы отсечек, пример подстановки, смысл AUC и отличие AP от трапеций. Оставить предупреждения о редком классе, неопределённом Precision без тревог и равных scores.
5. Проверить расчёты тестами, пересобрать SVG и PDF, визуально проверить страницу 2, неизменность остальных страниц, локальную веб-версию на телефоне/десктопе и обе темы. Провести независимое ревью, затем commit/push отдельной ветки. Общий деплой требует одобрения проверенной ревизии.

Источники: скриншоты пользователя из видео https://www.youtube.com/watch?v=v6PPG8J_Egs; определения ROC и PR и техническая точка PR (0,1) в официальных https://scikit-learn.org/stable/modules/generated/sklearn.metrics.roc_curve.html и https://scikit-learn.org/stable/modules/generated/sklearn.metrics.precision_recall_curve.html.

## Результат проверки

- 4 offline unittest: счётчики выбранных порогов, одновременное включение нулевых scores, точные площади, открытые пунктирные SVG-линии (закрытые линии при SVG-экспорте перекрывали пробелы обратным штрихом; исправлено и покрыто тестом).
- PDF пересобран штатным генератором, 3 страницы; страница 2 визуально проверена после финальной правки, текст страниц 1 и 3 совпадает с исходным.
- SVG проходят XML-проверку, размеры совпадают с Markdown; нет script/foreignObject. Графики в PDF и SVG создаются из одних координат.
- Веб-проверка: 1440×1100 и 390×844, светлая/тёмная темы, оба изображения загружены, подписи/оси/пунктиры читаемы, переполнения страницы и ошибок браузера нет. На маленьком экране доступно открытие исходного SVG по нажатию.
- 7 frontend-тестов cheatsheets.test.ts и production build успешны; остаётся существующее предупреждение о размере chunks.
- Независимое ревью code_reviewer, включая исправление экспорта пунктиров: замечаний нет. Auth, БД и инфраструктура не менялись.
