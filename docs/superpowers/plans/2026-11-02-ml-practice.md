# Самостоятельный HTML-практикум по метрикам ML

## Результат

Один HTML-файл, который можно скачать и открыть без интернета. 14 задач по пяти переданным видео: базовые метрики, пороги и ROC/PR, усреднение, регрессия, выбор метрики/порога под ограничения. Условия и исходные графики видны сразу; формулы и пошаговые решения раскрываются отдельно. Новая функциональность не подключается к авторизации, оценщику или базе приложения.

## План реализации

1. Сопоставить главы/описания авторов и авторский конспект selfedu с типами задач. Сохранить пять прямых ссылок и назначение каждого видео внутри практикума. Не выдавать авторские задачи за дословную расшифровку роликов.
2. `content/practice/ml-metrics.json`: условия, формулы, решения и данные графиков. Данные с девятью scores взяты с ранее переданного скриншота; другие числовые примеры самостоятельные.
3. `scripts/templates/ml-practice.html`: автономный адаптивный интерфейс, графики SVG, заметки и самостоятельная отметка «Решено», навигация по темам, светлая/тёмная темы. Решения закрыты при каждом открытии страницы. Фильтры не удаляют ответы.
4. `scripts/build_ml_practice.py`: проверка авторского HTML и схемы, безопасное встраивание JSON и локальных шрифтов, генерация `frontend/public/practice/ml-metrics.html`. Файл самодостаточен, зависимости нужны только при авторинге.
5. Проверить числа независимо; проверить сборку/автономность, скрытые решения, сохранение заметок, фильтры и сброс открытых разборов в браузере. Посмотреть десктоп/телефон и обе темы. Независимое ревью перед commit/push.

## Данные и границы

Только учебные синтетические данные. Заметки хранятся в localStorage этого браузера, без сетевой отправки и аналитики; при недоступном/переполненном хранилище ввод продолжает работать, интерфейс честно показывает отсутствие сохранения. Решения находятся внутри скачанного HTML намеренно — это самостоятельная практика, не защищённый экзамен. Серверный `reference_answer` не используется и не экспортируется. Ссылки на видео открываются только по действию пользователя.

## Проверка источников

Использованы сохранённые публичные метаданные оригинальных страниц YouTube (автор, описание и подробные главы) для всех пяти видео и авторский текст https://proproprogs.ru/ml/ml-pokazateli-precision-i-recall-f-mera. Прямое открытие видео через web в этой сессии не вернуло страницы; полный просмотр роликов не заявляется. Определения и ограничения сверяются с https://scikit-learn.org/stable/modules/model_evaluation.html. Отдельно сохраняются различия AP/трапеций, неопределённого Precision, равных scores, macro-F1/средних P/R и условий micro=Accuracy.

Публикация на общем сайте в эту задачу не включена: сначала готовый локальный HTML и проверенная ревизия для просмотра.

## Проверка и ревью

- 4 Python-теста: состав практикума, допустимый авторский HTML/ссылки/координаты, безопасное JSON-встраивание и автономность, расчёты по данным графиков.
- 6 Node-тестов для `scripts/templates/ml-practice-state.js`: старая вкладка, независимые поля, storage events, dirty ввод, quota/retry, миграция и недоступное хранилище.
- Заметки и отметки сохраняются отдельными ключами по полям; нет записи снимка при закрытии неизменённой вкладки. Проверено также двумя настоящими вкладками.
- Локальный браузер: 14 задач, 0 раскрытых решений при старте и после reload; заметки/отметки переживают reload; фильтры не теряют записи; повторный мобильный переход работает, увеличенный график прокручивается.
- Визуальный просмотр: 1440×1000 и 390×844, обе темы; page overflow=false; графики/таблицы/раскрытия читаемы, ошибок консоли нет.
- Полная production-сборка frontend проходит, копия HTML в dist совпадает побайтно. Существующее предупреждение о размере JS chunks основного приложения остаётся и к автономному HTML не относится.
- Независимое ревью: найдены и исправлены потеря записей между вкладками и повторная мобильная навигация. Повторное ревью, включая финальные правки, без замечаний.
- Встроенный браузер разрешает только HTTP(S) и отклонил `file://`; обходов не предпринималось. Интерактивная проверка выполнена на уже открытой локальной HTTP-копии. Отсутствие внешних ресурсов и наличие встроенных шрифтов/данных/скриптов проверены отдельно.
