# Задачи, gather и отмена

> Цель урока: научиться запускать корутины **конкурентно** (а не последовательно),
> понять разницу между `await` по очереди и `gather`, и разобраться с отменой и
> таймаутами. Здесь кроется главный смысл asyncio — делать много ожиданий
> одновременно; и здесь же частый вопрос «почему ваш async-код не быстрее
> синхронного».

## create_task: запуск в фоне

Просто `await` одной корутины за другой выполняет их **последовательно** — это не
даёт выигрыша. Чтобы запустить корутину **конкурентно**, её оборачивают в
**задачу (Task)** через `asyncio.create_task()` — это **планирует** корутину в
цикле немедленно, не дожидаясь её:

```python
# ПЛОХО: последовательно, 3 секунды суммарно
await fetch(a)        # ждём
await fetch(b)        # потом ждём
await fetch(c)

# ХОРОШО: конкурентно, ~1 секунда (все ждут одновременно)
t1 = asyncio.create_task(fetch(a))     # запланирована, начала работать
t2 = asyncio.create_task(fetch(b))
t3 = asyncio.create_task(fetch(c))
await t1; await t2; await t3           # ждём уже запущенные
```

`Task` — это «корутина, поставленная на исполнение в цикл» (подкласс Future). Сразу
после `create_task` она начинает продвигаться при ближайшем `await`. Это и есть
способ получить конкурентность: запустить много ожиданий, потом собрать
результаты.

**Аналогия.** `await` по очереди — заказать кофе, дождаться, потом заказать
сэндвич, дождаться. `create_task` — сделать оба заказа сразу, а потом забрать
готовое: пока готовят кофе, готовится и сэндвич.

## gather, wait, as_completed

Высокоуровневые способы запустить и собрать **много** корутин конкурентно:

- **`asyncio.gather(*coros)`** — запускает все конкурентно и возвращает список
  результатов **в порядке аргументов**, дождавшись всех. Если любая упадёт —
  по умолчанию исключение пробрасывается (или собирается при
  `return_exceptions=True`).
- **`asyncio.as_completed(coros)`** — отдаёт результаты **по мере готовности**
  (кто первый закончил).
- **`asyncio.TaskGroup`** (3.11+) — современный структурированный способ:
  гарантирует, что все задачи завершатся/отменятся вместе (при ошибке одной
  остальные отменяются).

```python
results = await asyncio.gather(fetch(a), fetch(b), fetch(c))   # [ra, rb, rc]

async with asyncio.TaskGroup() as tg:        # 3.11+: структурная конкурентность
    tg.create_task(fetch(a))
    tg.create_task(fetch(b))
```

`gather` — рабочая лошадка для «сделать N запросов параллельно». `TaskGroup` —
рекомендуемый современный подход, потому что аккуратно обрабатывает ошибки и
отмену группы.

**Аналогия.** `gather` — раздать N поручений курьерам и ждать, пока вернутся все,
получив отчёты по порядку. `as_completed` — принимать отчёты по мере возвращения.
`TaskGroup` — бригадир, который следит, чтобы вся бригада закончила вместе, а при
ЧП у одного — отозвал всех.

## Отмена и таймауты

asyncio даёт **кооперативную отмену**: задаче можно сказать «прекрати», и при
следующем `await` внутри неё поднимется **`asyncio.CancelledError`**.

```python
task = asyncio.create_task(long_job())
task.cancel()                              # запросить отмену
try:
    await task
except asyncio.CancelledError:
    ...                                    # задача отменена

# таймаут: отменить, если не успела
async with asyncio.timeout(5):             # 3.11+
    await slow_operation()
# или: await asyncio.wait_for(slow_operation(), timeout=5)
```

Важные нюансы: отмена **кооперативная** — задача отменяется в точке `await`, а не
мгновенно посреди синхронного блока. `CancelledError` стоит **не глушить** молча
(иначе отмена не сработает); если в `finally` нужна очистка — она выполнится.
Таймауты (`asyncio.timeout`, `wait_for`) реализованы через ту же отмену.

**Аналогия.** Отмена — попросить сотрудника свернуться: он остановится на ближайшей
естественной паузе (`await`), а не бросит дело посреди операции. Таймаут — будильник,
который по истечении времени и подаёт эту команду «сворачивайся».

## Памятка для собеседования

- `await` по очереди = **последовательно** (медленно). Для конкурентности —
  **`asyncio.create_task`** (планирует корутину сразу) или `gather`.
- **`gather(*coros)`** — все конкурентно, результаты по порядку аргументов;
  `as_completed` — по мере готовности; **`TaskGroup`** (3.11+) — структурная
  конкурентность с корректной отменой при ошибке.
- **Отмена кооперативная**: `task.cancel()` → `CancelledError` в точке `await`;
  не глушить его молча. Таймауты — `asyncio.timeout` / `wait_for`.

## Частые ошибки в ответах

- `await`-ить корутины по очереди и думать, что это конкурентно (нужен
  create_task/gather).
- Не знать `gather`/`TaskGroup` или не понимать порядок результатов в `gather`.
- Считать, что `cancel()` мгновенно убивает задачу (отмена кооперативная, в точке
  `await`).
- Глушить `CancelledError`, ломая механизм отмены/таймаутов.
