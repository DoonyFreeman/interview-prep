# Списки: динамический массив и сортировка

> Цель урока: понять, что `list` — это динамический массив (а не связный список),
> какие операции дёшевы, а какие дороги, и как работает сортировка Timsort.
> Сложность операций со списком — обязательный вопрос, на нём проверяют, понимает
> ли человек, что под капотом.

## Список — это динамический массив

`list` в Python реализован как **динамический массив** — непрерывный блок
указателей на объекты, который автоматически растёт. Это **не связный список**
(распространённое заблуждение из-за названия). Отсюда характеристики сложности:

- **Доступ по индексу `lst[i]`** — **O(1)**: прямой переход по адресу.
- **`append`** — **амортизированно O(1)**: массив переаллоцируется с запасом
  (растёт примерно в ~1.125 раза), поэтому большинство append'ов мгновенны, а
  редкие — с копированием.
- **`insert(0, x)` / `pop(0)` / `del lst[0]`** — **O(n)**: вставка/удаление в
  начале или середине сдвигает все последующие элементы.
- **Поиск `x in lst`** — **O(n)**: линейный перебор (в отличие от `set`/`dict`).

```python
lst.append(x)      # O(1) амортизированно — добавить в конец
lst.pop()          # O(1) — удалить с конца
lst.insert(0, x)   # O(n) — сдвиг всех элементов
x in lst           # O(n) — линейный поиск
```

Если нужны частые вставки/удаления **с обоих концов**, берут `collections.deque`
(O(1) с краёв). Для проверки принадлежности — `set` (O(1)).

**Аналогия.** Список — это ряд пронумерованных ячеек на полке: достать ячейку №5
мгновенно (O(1)), но вставить новую в начало — значит сдвинуть все остальные
вправо (O(n)). Дописать в конец — просто положить в следующую свободную ячейку.

## Срезы (slicing)

Срез `lst[start:stop:step]` создаёт **новый список** (копию подмножества):

```python
lst = [0, 1, 2, 3, 4]
lst[1:4]      # [1, 2, 3] — новый список
lst[::-1]     # [4, 3, 2, 1, 0] — разворот
lst[:]        # поверхностная копия всего списка
lst[::2]      # [0, 2, 4] — каждый второй
```

Срез безопасен к выходу за границы (`lst[1:100]` не падает). Поскольку срез
создаёт копию, `lst[:]` — идиома поверхностного копирования. Срезам можно и
**присваивать** (`lst[1:3] = [9]` — заменить участок, меняя длину).

**Аналогия.** Срез — как фотокопия части документа: оригинал не трогается, у вас на
руках отдельная копия выбранных страниц.

## Сортировка: sort vs sorted, Timsort

Два способа сортировки:

- **`lst.sort()`** — сортирует **на месте**, возвращает `None`, меняет сам список.
- **`sorted(lst)`** — возвращает **новый** отсортированный список, исходный не
  трогает (работает с любым iterable).

Оба используют **Timsort** — гибрид сортировки слиянием и вставками,
разработанный для Python. Его свойства: **стабильный** (равные элементы сохраняют
исходный порядок), **адаптивный** (быстр на частично отсортированных данных,
использует уже упорядоченные «прогоны»), сложность **O(n log n)** в худшем случае,
O(n) на почти отсортированных.

Ключи и направление:

```python
users.sort(key=lambda u: u.age)          # сортировка по полю
sorted(words, key=len, reverse=True)     # по длине, по убыванию
sorted(items, key=lambda x: (x.cat, -x.price))  # по нескольким ключам
```

**Стабильность** позволяет сортировать в несколько проходов: сначала по
вторичному ключу, потом по первичному — порядок внутри групп сохранится.

**Аналогия.** Timsort — как опытный сортировщик, который замечает уже разложенные
по порядку пачки карт и не пересортировывает их зря, а только сливает. Стабильность
— при равных картах он не меняет их относительный порядок.

## Памятка для собеседования

- `list` — **динамический массив** (не связный список): индекс O(1), `append`
  амортизированно O(1), вставка/удаление в начале/середине O(n), `in` — O(n).
- Для краёв с двух сторон — `deque` (O(1)); для проверки принадлежности — `set`
  (O(1)).
- Срез `lst[a:b:c]` создаёт **новую** копию; `lst[:]` — поверхностная копия,
  `lst[::-1]` — разворот.
- `sort()` — на месте, возвращает None; `sorted()` — новый список из любого
  iterable.
- Сортировка — **Timsort**: стабильная, адаптивная, O(n log n). `key=` для
  ключа, `reverse=` для направления; стабильность даёт многоуровневую сортировку.

## Частые ошибки в ответах

- Называть `list` связным списком; не знать, что вставка в начало — O(n).
- Думать, что `x in lst` быстрый (он O(n); для O(1) нужен set/dict).
- Писать `lst = lst.sort()` и получить `None` (sort возвращает None, не список).
- Не знать про Timsort и его стабильность/адаптивность.
- Считать, что срез меняет исходный список (он создаёт копию).
