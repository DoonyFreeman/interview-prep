# collections и itertools

> Цель урока: познакомиться со «вторым этажом» стандартной библиотеки — готовыми
> структурами из `collections` и ленивыми инструментами `itertools`. Знание этих
> модулей на собесе показывает, что человек пишет идиоматичный Python и не
> изобретает велосипеды.

## deque: очередь с двух концов

`collections.deque` — **двусвязная** структура (дек), оптимизированная для
добавления и удаления **с обоих концов за O(1)**. Это решает слабое место списка,
где `insert(0, ...)`/`pop(0)` — O(n).

```python
from collections import deque

q = deque([1, 2, 3])
q.appendleft(0)    # O(1) — список тут был бы O(n)
q.append(4)        # O(1)
q.popleft()        # O(1) — взять из начала
q = deque(maxlen=100)   # кольцевой буфер: при переполнении вытесняет старые
```

Применения: **очередь FIFO** (для BFS-обхода графов), **стек**, скользящее окно
последних N элементов (`maxlen`). Минус относительно списка — доступ по индексу в
середине O(n) (это не массив).

**Аналогия.** `deque` — это труба, открытая с обоих концов: класть и вынимать
шарики удобно с любой стороны. Список — труба, запаянная с одного конца: с
запаянного добавлять дорого.

## Counter, defaultdict, ChainMap

Три специализированных словаря:

- **`Counter`** — подсчёт частот. `Counter("mississippi")` посчитает буквы;
  `.most_common(n)` вернёт топ-N; поддерживает арифметику (`c1 + c2`).
- **`defaultdict(factory)`** — значение по умолчанию для нового ключа: убирает
  проверки «есть ли ключ». `defaultdict(list)` — группировка, `defaultdict(int)`
  — счётчики.
- **`ChainMap`** — объединяет несколько словарей в один вид без копирования; поиск
  идёт по очереди. Удобно для слоёв конфигурации (CLI → env → defaults).

```python
from collections import Counter, defaultdict

Counter(["a", "b", "a", "c", "a"]).most_common(1)   # [('a', 3)]

groups = defaultdict(list)
for w in words:
    groups[len(w)].append(w)     # группировка по длине без проверок
```

**Аналогия.** `Counter` — это турникет, считающий, сколько раз прошёл каждый;
`defaultdict` — гардеробщик, сам вешающий вешалку под новый ключ; `ChainMap` —
стопка прозрачных листов: смотришь сверху и видишь первое непустое значение.

## itertools: ленивые конвейеры

`itertools` — набор **ленивых** (генераторных) инструментов для работы с
последовательностями: они не материализуют результат, а отдают по одному
элементу, экономя память и позволяя работать с бесконечными потоками.

```python
import itertools as it

it.chain([1, 2], [3, 4])          # 1 2 3 4 — склейка итерируемых
it.islice(stream, 0, 10)          # первые 10 без загрузки всего
it.groupby(sorted_data, key=...)  # группировка ПОДРЯД идущих (нужна сортировка!)
it.product([1, 2], ["a", "b"])    # декартово произведение
it.combinations(items, 2)         # все пары
it.count(0, 2)                    # бесконечный 0,2,4,6,...
it.cycle(["x", "y"])              # бесконечное повторение
it.accumulate([1,2,3,4])          # нарастающие суммы 1,3,6,10
```

Ключевой подвох — **`groupby` группирует только подряд идущие равные ключи**,
поэтому данные нужно сначала отсортировать по тому же ключу. Сила `itertools` — в
**конвейерах**: соединяя ленивые шаги, можно обрабатывать гигабайтные потоки при
почти константной памяти.

**Аналогия.** `itertools` — это насадки на конвейерную ленту: одна склеивает
потоки, другая отрезает первые N деталей, третья комбинирует пары. Детали едут по
одной (лениво), лента не забивается, а из насадок собирается любая обработка.

## Памятка для собеседования

- **`deque`** — добавление/удаление с обоих концов **O(1)** (список: начало —
  O(n)); FIFO-очередь (BFS), стек, окно последних N (`maxlen`).
- **`Counter`** — частоты, `.most_common(n)`, арифметика; **`defaultdict`** —
  значение по умолчанию (группировки/счётчики); **`ChainMap`** — слои словарей без
  копирования.
- **`itertools`** — ленивые инструменты: `chain`, `islice`, `groupby`, `product`,
  `combinations`, `count`, `cycle`, `accumulate`; основа памяти-эффективных
  конвейеров и бесконечных потоков.
- `groupby` группирует только **подряд идущие** ключи → сначала сортировка.

## Частые ошибки в ответах

- Использовать список как очередь (`pop(0)` — O(n)) вместо `deque`.
- Вручную писать подсчёт частот циклом вместо `Counter`.
- Городить проверки «if key in d» вместо `defaultdict`/`setdefault`.
- Ждать от `itertools.groupby` группировки несоседних элементов (он группирует
  только подряд).
- Не использовать ленивость `itertools` и держать большие промежуточные списки в
  памяти.
