# Метрики ML, практика 3: ошибки прогноза и цена недооценки

> **9 минут с практикой.** Теперь прогнозируем число заявок по сменам. Нулевая смена ломает одну метрику, а недооценка нагрузки оставляет команду без дежурных.

## Одинаковая средняя ошибка, разные последствия

В трёх сменах пришло **0, 2 и 18** заявок. Модель A ожидала **1, 4 и 15**, модель B — **0, 2 и 12**. Пройди расчёт по шагам.

**MAE** — средний модуль ошибки. **MSE** — средний квадрат ошибки. **RMSE** — корень из MSE. Квадраты сильнее штрафуют крупные промахи. Если для всех наблюдений нужен один постоянный прогноз, MAE минимизирует медиана, а MSE и RMSE — среднее.

**R²** сравнивает сумму квадратов ошибок с разбросом факта вокруг его среднего на оцениваемом наборе. При факте **2 и 4** средний ориентир **3** даёт сумму квадратов **2**, а прогноз **0 и 6** — **8**. Получаем **R² = 1 − 8/2 = −3**, то есть прогноз по квадратам хуже этого ориентира. Одинаковая абсолютная ошибка на данных с разным разбросом может дать разный R². **Adjusted R²** учитывает число признаков при сравнении регрессий на одной выборке. Для проверки будущего сравнивай с правилом, которому доступны только прошлые данные.

## Если фактическое значение равно нулю

| Метрика | Как считает | Что проверить |
| --- | --- | --- |
| **MAPE** | Среднее от абсолютной ошибки, делённой на модуль факта в каждой строке | При факте 0 знаменатель нулевой, при малом факте отдельная строка может раздуть отчёт. |
| **sMAPE** | Среднее от `2 × модуль ошибки / (модуль факта + модуль прогноза)` | Укажи правило для пары нулей. Малые значения всё ещё сильно влияют на долю. |
| **WAPE** | Сумма модулей ошибок / сумма модулей фактов. У модели A **6/20 = 30%** | Одиночные нули допустимы. Если весь факт нулевой, метрика не определена. Большие смены сильнее влияют на итог. |
| **MASE** | MAE на тесте / MAE наивного прогноза, рассчитанная на train | Сравнивает в масштабе наивной ошибки. Если она нулевая, метрика не определена. Для сезонного ряда используют сравнение с тем же местом прошлого сезона. |

Для MASE возьмём train **4, 6, 8, 10**. Наивный прогноз «как в прошлую смену» на train ошибается каждый раз на **2**. У модели A MAE теста тоже **2**, поэтому **MASE = 1**. Это сравнение с масштабом на train. Прямое сравнение моделей и наивного прогноза делай отдельно на общем тесте с одним горизонтом прогноза.

## Когда недооценка дороже

На крупной смене ожидали 15, пришло 18. Занижение на 3 требует искать людей в последний момент. Завышение на 3 оставляет немного запаса. **Pinball loss** с квантилем 0,9 штрафует одинаковые по модулю ошибки по-разному: **0,9 × 3 = 2,7** за занижение и **0,1 × 3 = 0,3** за завышение. Обучение с таким loss целится в **p90** числа заявок при заданных условиях. Если нужен диапазон, прогнозы **p10 и p90** задают интервал с номинальным покрытием 80%. Проверь фактическое покрытие и ширину на новых данных.

**Huber loss** квадратичен при малых ошибках и растёт линейно при больших. Он снижает влияние выбросов и симметричен по знаку. Функцию потерь выбирай под обучение, а в отчёте покажи понятные величины: **MAE в заявках**, частоту недооценки и ошибки по типам смен.

**Проверь себя.** Средний остаток модели A равен нулю. Можно ли по этому сказать, что она хорошо оценивает крупные смены?

```solution
Нет. В примере она переоценила обе маленькие смены, а крупную недооценила на три заявки. При усреднении знаки взаимно сократились. Разбей по типам смен и смотри средний остаток, MAE и количество примеров в каждом сегменте. На тех же сегментах сравни с простым прогнозом, например «как в прошлую сопоставимую смену».
```
