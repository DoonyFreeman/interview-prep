# Функции: аргументы, распаковка, first-class

> Цель урока: уверенно объяснять, как Python передаёт аргументы, что такое
> `*args`/`**kwargs` и распаковка, и почему функции — «объекты первого класса».
> Эти основы всплывают в каждом проекте (сигнатуры, декораторы, колбэки) и часто
> проверяются мелкими, но коварными вопросами на собесе.

## Виды аргументов

Python различает аргументы по способу передачи:

- **Позиционные** — по порядку: `f(1, 2)`.
- **Именованные (keyword)** — по имени: `f(x=1, y=2)`; порядок не важен.
- **Со значением по умолчанию** — `def f(x, y=10)`; делает аргумент
  необязательным.

Можно жёстко задавать способ передачи специальными разделителями в сигнатуре:

```python
def f(pos_only, /, normal, *, kw_only):
    ...
# pos_only — только позиционно
# kw_only  — только по имени
```

`/` означает «всё слева — только позиционные», `*` — «всё справа — только
именованные». Это используется в стандартной библиотеке и помогает строить
стабильные API (имя позиционного параметра можно менять, не ломая вызовы).

**Аналогия.** Позиционные аргументы — как ингредиенты по порядку в рецепте
(«первое — мука, второе — сахар»); именованные — подписанные баночки («сахар»,
«мука»), которые не перепутать. `*`/`/` — правила, что класть строго по порядку, а
что только по подписи.

## *args и **kwargs

Звёздочки позволяют принимать **переменное число** аргументов:

- **`*args`** собирает лишние **позиционные** аргументы в **кортеж**.
- **`**kwargs`** собирает лишние **именованные** аргументы в **словарь**.

```python
def log(level, *args, **kwargs):
    print(level, args, kwargs)

log("INFO", 1, 2, user="bob", id=7)
# INFO (1, 2) {'user': 'bob', 'id': 7}
```

Главное применение — **обёртки и декораторы**, которые должны прозрачно
пробрасывать любые аргументы в обёрнутую функцию: `def wrapper(*args, **kwargs):
return func(*args, **kwargs)`. Порядок в сигнатуре строгий: обычные → `*args` →
keyword-only → `**kwargs`.

**Аналогия.** `*args` — коробка «всё остальное по порядку», `**kwargs` — коробка
«всё остальное с ярлыками». Обёртка берёт обе коробки и не глядя передаёт дальше —
поэтому декоратор подходит к функции с любой сигнатурой.

## Распаковка

Звёздочки работают и в **обратную сторону** — при вызове и присваивании, чтобы
**разложить** коллекцию:

```python
nums = [1, 2, 3]
print(*nums)              # print(1, 2, 3) — распаковка списка в аргументы

params = {"sep": "-", "end": "!\n"}
print("a", "b", **params) # именованные из словаря

a, *rest = [1, 2, 3, 4]   # a=1, rest=[2,3,4] — «звёздная» распаковка
first, *_, last = range(10)  # first=0, last=9, середина отброшена

merged = {**defaults, **overrides}   # слияние словарей
combined = [*list_a, *list_b]        # объединение списков
```

Это идиоматичный способ передавать заранее собранные параметры, сливать
структуры и «расхватывать» части последовательности. Один и тот же синтаксис
`*`/`**` в **определении** функции собирает, а в **вызове/присваивании** —
раскладывает.

**Аналогия.** Распаковка — как высыпать содержимое пакета на стол по отдельным
ячейкам. `*` сыплет «в ряд», `**` раскладывает «по подписанным местам».

## Функции как объекты первого класса

В Python функция — **обычный объект**: её можно присвоить переменной, положить в
список/словарь, передать в другую функцию и вернуть из неё. На этом стоят
**декораторы, колбэки, стратегии, реестры обработчиков**.

```python
def double(x): return x * 2
def square(x): return x * x

ops = {"double": double, "square": square}   # функции как значения
print(ops["square"](5))                       # 25

def apply(fn, value):                          # функция как аргумент
    return fn(value)
print(apply(double, 10))                       # 20
```

**Функции высшего порядка** — те, что принимают или возвращают функции (`map`,
`filter`, `sorted(key=...)`, декораторы). **`lambda`** — короткая анонимная
функция-выражение (`key=lambda x: x.age`), удобная как одноразовый аргумент; для
чего-то сложнее одной строки лучше обычный `def`.

```python
users.sort(key=lambda u: u.created_at)   # функция-ключ сортировки
```

**Аналогия.** «Объект первого класса» = у функции те же гражданские права, что и у
числа: её можно «передать по почте», «положить в ящик», «вернуть в посылке».
Именно это позволяет конструировать поведение из функций, как из деталей.

## Памятка для собеседования

- Аргументы: позиционные, именованные, со значением по умолчанию. `/` — только
  позиционные слева, `*` — только именованные справа.
- **`*args`** → кортеж лишних позиционных; **`**kwargs`** → словарь лишних
  именованных. Основа прозрачных обёрток/декораторов.
- Та же `*`/`**` при **вызове/присваивании** — **распаковка**: `print(*xs)`,
  `{**a, **b}`, `a, *rest = ...`.
- Функции — **объекты первого класса**: присваиваются, передаются, возвращаются,
  хранятся. Отсюда функции высшего порядка и декораторы.
- `lambda` — короткая анонимная функция-выражение для одноразового использования
  (`key=`, колбэки).

## Частые ошибки в ответах

- Путать сбор (`def f(*args)`) и распаковку (`f(*args)`) — один синтаксис, разные
  стороны.
- Не знать порядок в сигнатуре (обычные → `*args` → keyword-only → `**kwargs`).
- Ставить изменяемое значение по умолчанию (`def f(x=[])`) — ловушка из урока про
  копирование.
- Считать `lambda` принципиально иной сущностью, чем `def` — это та же функция,
  лишь анонимная и ограниченная одним выражением.
- Не уметь связать «функции — объекты» с тем, как вообще работают декораторы.
