# Графы: BFS, DFS, кратчайшие пути

> Цель урока: понять представления графов и базовые алгоритмы — BFS, DFS,
> топологическую сортировку и Dijkstra. Графовые задачи часто маскируются (сетка,
> зависимости, связи), и умение «увидеть граф» плюс выбрать обход — ценный навык.

## Представления графа

**Граф** — узлы (вершины) и **рёбра** (связи между ними); бывает
**ориентированный** (рёбра со стрелками) или нет, **взвешенный** (у рёбер веса)
или нет. Два основных представления:

- **Список смежности (adjacency list)** — для каждой вершины список соседей.
  **Память O(V+E)**, эффективен для **разреженных** графов (рёбер мало). Основной
  выбор на практике.
- **Матрица смежности (adjacency matrix)** — таблица `V×V`, где `[i][j]` = есть ли
  ребро. **Память O(V²)**, проверка ребра за O(1); хорош для **плотных** графов.

```python
graph = {                    # список смежности
    "A": ["B", "C"],
    "B": ["D"],
    "C": ["D"],
    "D": [],
}
```

Часто граф **спрятан**: сетка (клетки — вершины, соседи — рёбра), зависимости задач,
связи пользователей, состояния. Распознать «это граф» — половина решения.

**Аналогия.** Список смежности — записная книжка контактов (у каждого свой список
знакомых); матрица — таблица «кто с кем знаком» галочками. Для большой компании с
редкими связями книжка компактнее, для тесного кружка таблица удобнее.

## BFS и DFS

Два фундаментальных обхода графа:

- **BFS (поиск в ширину)** — обходит вершины **по слоям** (сначала всех соседей,
  потом соседей соседей) через **очередь** (`deque`). Находит **кратчайший путь по
  числу рёбер** в невзвешенном графе. O(V+E).
- **DFS (поиск в глубину)** — идёт **вглубь** по одной ветви до упора, потом
  возвращается; **рекурсия** или явный стек. Для обнаружения циклов, компонент
  связности, топосортировки. O(V+E).

```python
from collections import deque

def bfs(graph, start):
    visited = {start}
    q = deque([start])
    while q:
        node = q.popleft()
        for nb in graph[node]:
            if nb not in visited:      # ОБЯЗАТЕЛЬНО отмечать посещённые
                visited.add(nb)
                q.append(nb)
```

**Критично — отмечать посещённые** (`visited`), иначе в графе с циклами обход
зациклится (в отличие от дерева, где циклов нет). Выбор: нужен **кратчайший путь по
рёбрам** → BFS; нужно «дойти до конца ветки», циклы, топосорт → DFS.

**Аналогия.** BFS — как круги на воде от брошенного камня: волна расходится слоями,
ближайшее достигается первым (кратчайший путь). DFS — как идти по лабиринту,
сворачивая в первый коридор до тупика, потом возвращаясь.

## Топологическая сортировка

**Топологическая сортировка** упорядочивает вершины **ориентированного
ациклического графа (DAG)** так, что каждое ребро идёт «вперёд»: если A → B, то A
**раньше** B. Это порядок выполнения при **зависимостях**.

```text
Задачи со связями «сначала A, потом B»: компиляция модулей, установка пакетов,
расписание курсов с пререквизитами, порядок миграций.
```

Два способа: **алгоритм Кана** (BFS по вершинам с нулевой входящей степенью:
берём «без зависимостей», удаляем, повторяем) или **DFS с post-order**
(развернуть). Важно: топосорт **существует только для DAG** — если есть **цикл**
(взаимные зависимости), порядок невозможен, и алгоритм это обнаруживает (полезно
для **поиска циклических зависимостей**, как в импортах из курса Python Core).

**Аналогия.** Топосорт — как порядок надевания одежды: носки до ботинок, рубашку до
пиджака. Если же «A нужен до B, а B до A» (цикл) — одеться невозможно, и это сигнал
о противоречии.

## Кратчайшие пути: Dijkstra

Для **взвешенного** графа кратчайший путь по сумме весов BFS не находит (он считает
рёбра, не веса). **Алгоритм Дейкстры (Dijkstra)** находит кратчайшие пути от
вершины до всех остальных при **неотрицательных** весах, используя **кучу
(приоритетную очередь)**: всегда берём ближайшую необработанную вершину и
«релаксируем» её соседей.

```python
import heapq
def dijkstra(graph, start):           # graph: {u: [(v, weight), ...]}
    dist = {start: 0}
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)       # ближайшая вершина
        if d > dist.get(u, float("inf")): continue
        for v, w in graph[u]:
            nd = d + w
            if nd < dist.get(v, float("inf")):
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist
```

Сложность с кучей — **O((V+E) log V)**. Ограничение: **неотрицательные веса** (для
отрицательных — Беллман-Форд). Знать «BFS для невзвешенного, Dijkstra для
взвешенного с неотрицательными весами» — частый вопрос.

**Аналогия.** Dijkstra — как навигатор, который всегда продолжает маршрут от
ближайшей ещё не обработанной точки, обновляя оценки до соседей. Куча держит «какая
точка сейчас ближе всего» наготове.

## Памятка для собеседования

- Представления: **список смежности** (O(V+E), разреженные — выбор по умолчанию)
  vs **матрица** (O(V²), плотные, проверка ребра O(1)). Граф часто скрыт (сетка,
  зависимости).
- **BFS** (очередь, по слоям) — **кратчайший путь по рёбрам** в невзвешенном;
  **DFS** (рекурсия/стек) — циклы, компоненты, топосорт. Оба O(V+E); **отмечать
  visited** (циклы!).
- **Топосортировка** — порядок для **DAG** (зависимости); только без циклов
  (обнаружение циклов). Кан (BFS) / DFS post-order.
- **Dijkstra** (куча) — кратчайшие пути во взвешенном графе с **неотрицательными**
  весами, O((V+E)log V); BFS для весов не годится.

## Частые ошибки в ответах

- Забыть `visited` и зациклиться на графе с циклами.
- Использовать BFS для кратчайшего пути во **взвешенном** графе (нужен Dijkstra).
- Применять Dijkstra к графу с **отрицательными** весами (нужен Беллман-Форд).
- Не распознавать граф в задаче (сетка/зависимости) или путать BFS-очередь и
  DFS-стек.
