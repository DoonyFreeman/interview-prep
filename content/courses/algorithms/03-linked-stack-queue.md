# Связные списки, стек и очередь

> Цель урока: понять линейные структуры данных — связный список, стек, очередь,
> дек — их сложности и типичные применения. Это базовые «кирпичики», на которых
> строятся более сложные алгоритмы, и частые вопросы «когда стек, когда очередь».

## Связный список

**Связный список (linked list)** — последовательность **узлов**, где каждый хранит
значение и **ссылку на следующий** (в двусвязном — и на предыдущий). В отличие от
массива, элементы **не лежат подряд** в памяти.

```python
class Node:
    def __init__(self, val, next=None):
        self.val, self.next = val, next
```

Сложности — зеркальны массиву:

- **Вставка/удаление в известном месте — O(1)** (перецепить ссылки), без сдвига
  элементов. Это сила списка.
- **Доступ по индексу / поиск — O(n)** (надо идти от головы). Это его слабость; нет
  «прыжка» по адресу, как в массиве.

Классические задачи: **разворот** списка (перецепить ссылки), **поиск цикла**
(быстрый/медленный указатели — алгоритм Флойда), слияние отсортированных,
нахождение середины. В Python списком пользуются редко (есть `list`/`deque`), но на
собесе он проверяет работу с указателями.

**Аналогия.** Связный список — цепочка людей, держащихся за руки: вставить нового
посередине легко (двое расцепились, взяли его за руки), но чтобы найти десятого,
надо пройти по цепочке от начала. Массив — пронумерованные кресла: к десятому
подходишь сразу, но вставить новое в начало — пересадить всех.

## Стек (LIFO)

**Стек** — структура **LIFO (Last In, First Out)**: последний добавленный
извлекается первым. Две операции — **push** (положить наверх) и **pop** (снять
сверху), обе **O(1)**. В Python стек — это обычный `list` (`append`/`pop`).

```python
stack = []
stack.append(x)     # push — O(1)
top = stack.pop()   # pop  — O(1), снимает последний
```

Где применяется: **проверка парности скобок**, **отмена действий (undo)**, обход
истории, вычисление выражений, и главное — **рекурсия** реализована через стек
вызовов (а любую рекурсию можно развернуть в явный стек). Признак «нужен стек» —
«последнее открытое закрывается первым», вложенность, возврат назад.

**Аналогия.** Стек — стопка тарелок: кладёшь и берёшь только сверху. Последняя
поставленная тарелка снимается первой. Так же стек вызовов: последняя вызванная
функция возвращается первой.

## Очередь и дек (FIFO)

**Очередь** — структура **FIFO (First In, First Out)**: первый добавленный
извлекается первым. **enqueue** (в конец) и **dequeue** (из начала). Важно: в
Python для очереди берут **`collections.deque`**, а **не** `list`, потому что
`list.pop(0)` — O(n) (сдвиг), а `deque.popleft()` — **O(1)**.

```python
from collections import deque
q = deque()
q.append(x)        # enqueue — O(1)
first = q.popleft()  # dequeue — O(1) (у list было бы O(n)!)
```

**Дек (deque)** — двусторонняя очередь: добавление/удаление **с обоих концов за
O(1)**; объединяет стек и очередь. Применения очереди: **обход в ширину (BFS)**,
планировщики задач, буферы, потоковая обработка. Признак «нужна очередь» —
«обрабатываем в порядке поступления», «уровень за уровнем».

**Аналогия.** Очередь — очередь в кассу: кто пришёл первым, того обслужат первым
(FIFO). Дек — очередь, открытая с обоих концов, куда можно встать и уйти и спереди,
и сзади.

## Памятка для собеседования

- **Связный список**: вставка/удаление в известном месте **O(1)** (перецепить
  ссылки), доступ по индексу/поиск **O(n)**. Задачи: разворот, цикл (Флойд,
  fast/slow), слияние.
- **Стек (LIFO)** — push/pop с конца O(1); скобки, undo, вычисления, **рекурсия**
  = стек вызовов. В Python — `list`.
- **Очередь (FIFO)** — для **BFS**, планировщиков; в Python — **`deque`**
  (`popleft` O(1)), не `list` (`pop(0)` O(n)). **Дек** — оба конца O(1).

## Частые ошибки в ответах

- Использовать `list.pop(0)` как очередь (O(n)) вместо `deque.popleft()` (O(1)).
- Считать, что доступ по индексу в связном списке — O(1) (он O(n)).
- Путать LIFO (стек) и FIFO (очередь) и их применения (DFS vs BFS).
- Не связывать стек с рекурсией (стек вызовов / разворот рекурсии в явный стек).
