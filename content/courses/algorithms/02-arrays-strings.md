# Массивы и строки: приёмы

> Цель урока: освоить три приёма, которые решают огромную долю задач на массивы и
> строки — два указателя, скользящее окно и хэширование. Это «рабочая лошадка»
> алгоритмических собеседований; узнавание паттерна часто важнее знания конкретных
> алгоритмов.

## Два указателя

**Два указателя (two pointers)** — приём, где по массиву движутся **два индекса**,
заменяя вложенный цикл и снижая сложность с O(n²) до **O(n)**. Варианты:

- **С разных концов навстречу** — для **отсортированного** массива: ищем пару с
  нужной суммой, проверяем палиндром, сжимаем интервал.
- **Один за другим (fast/slow)** — удаление дубликатов на месте, поиск цикла в
  списке.

```python
# пара с суммой target в ОТСОРТИРОВАННОМ массиве — O(n), без вложенного цикла
def two_sum_sorted(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo < hi:
        s = nums[lo] + nums[hi]
        if s == target: return (lo, hi)
        if s < target: lo += 1        # нужна сумма больше — двигаем левый
        else: hi -= 1                 # нужна меньше — двигаем правый
```

Ключевая идея — **отсортированность или структура** позволяет на каждом шаге
**отбросить** часть вариантов, двигая нужный указатель. Узнавание «тут можно двумя
указателями» экономит порядок сложности.

**Аналогия.** Два указателя — как двое, идущие навстречу по отсортированной полке и
сужающие поиск: видя, что сумма мала, левый делает шаг вперёд; велика — правый
отступает. Не нужно сравнивать каждого с каждым.

## Скользящее окно

**Скользящее окно (sliding window)** — для задач о **непрерывном подотрезке**
(подстрока, подмассив) с каким-то свойством: вместо перебора всех окон (O(n²))
поддерживаем **окно `[left, right]`**, двигая правую границу и подтягивая левую,
обновляя ответ — **O(n)**.

```python
# самая длинная подстрока без повторов — O(n)
def longest_unique(s):
    seen = {}
    left = best = 0
    for right, ch in enumerate(s):
        if ch in seen and seen[ch] >= left:
            left = seen[ch] + 1        # сдвигаем левую границу за дубликат
        seen[ch] = right
        best = max(best, right - left + 1)
    return best
```

Окно бывает **фиксированного** размера (среднее по k подряд) или **переменного**
(самый длинный/короткий подотрезок с условием). Признак задачи — «непрерывный
подотрезок», «подстрока», «подмассив» + условие (сумма, уникальность, ≤ k
различных).

**Аналогия.** Скользящее окно — как смотреть на текст через прорезь, которую то
расширяешь (двигаешь правый край), то сужаешь (левый), вместо того чтобы каждый раз
перечитывать весь фрагмент заново.

## Хэширование и префиксные суммы

Два приёма «памятью купить время»:

- **Хэш-таблица (множество/словарь)** — за **O(1)** проверять «видели ли»,
  считать частоты, искать дополнение. Превращает «для каждого ищем пару» из O(n²)
  в O(n) (как `two_sum` через `dict`). Базовый инструмент: дубликаты, анаграммы
  (по `Counter`), группировки.
- **Префиксные суммы (prefix sums)** — предпосчитанный массив, где `pre[i]` = сумма
  первых `i` элементов; тогда **сумма любого диапазона** `[l, r]` = `pre[r+1] -
  pre[l]` за **O(1)** вместо пересчёта. В связке с хэш-таблицей решает «число
  подмассивов с суммой k».

```python
# число подмассивов с суммой k — O(n) через префиксные суммы + хэш
def subarray_sum(nums, k):
    count = pre = 0
    seen = {0: 1}                      # префикс 0 встречался один раз
    for x in nums:
        pre += x
        count += seen.get(pre - k, 0)  # сколько раз был префикс pre-k
        seen[pre] = seen.get(pre, 0) + 1
    return count
```

Узнавание «здесь нужна хэш-таблица» или «префиксные суммы для диапазонных сумм» —
половина успеха в этой категории.

**Аналогия.** Префиксные суммы — как нарастающий итог в кассовой ленте: чтобы узнать
выручку за период, не складываешь чеки заново, а вычитаешь два итога. Хэш-таблица —
записная книжка «кого уже видел», чтобы не искать заново.

## Памятка для собеседования

- **Два указателя** — заменяют вложенный цикл на O(n): навстречу (отсортированный
  массив: пара/палиндром) или fast/slow (дубликаты, цикл). Идея — отбрасывать часть
  вариантов на каждом шаге.
- **Скользящее окно** — для **непрерывного подотрезка** с условием: окно
  `[left,right]`, двигаем границы, O(n). Фиксированное/переменное.
- **Хэш-таблица** — O(1) проверка/частоты/дополнение (two_sum, анаграммы);
  **префиксные суммы** — сумма диапазона за O(1) (`pre[r+1]-pre[l]`), с хэшем —
  «подмассивы с суммой k».

## Частые ошибки в ответах

- Решать вложенными циклами (O(n²)) там, где паттерн даёт O(n).
- Применять два указателя к неотсортированному массиву, где нужна сортировка/хэш.
- Не узнавать «скользящее окно» в задачах про подстроку/подмассив.
- Не использовать префиксные суммы для повторяющихся диапазонных запросов.
