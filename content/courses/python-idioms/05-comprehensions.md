# Comprehensions: списки, словари, множества

> Цель урока: освоить comprehensions — самый узнаваемый «питоничный» синтаксис для
> построения коллекций. Это одна из самых частых тем собеседования: просят
> переписать цикл в comprehension, объяснить вложенные и сказать, когда их **не**
> стоит применять.

## Основы: list, dict, set comprehension

**Comprehension** — компактный синтаксис, чтобы **построить коллекцию из
итерируемого** в одном выражении, заменяя цикл с `append`. Есть три вида плюс
генераторное выражение:

```python
# list comprehension — построить список
squares = [x * x for x in range(5)]            # [0, 1, 4, 9, 16]

# вместо многословного цикла:
squares = []
for x in range(5):
    squares.append(x * x)

# dict comprehension — построить словарь
name_len = {name: len(name) for name in names}

# set comprehension — построить множество (уникальные)
unique_lengths = {len(name) for name in names}

# генераторное выражение — ленивое, в круглых скобках (не материализует список)
total = sum(x * x for x in range(1_000_000))   # память ~константа
```

Разница со скобками: `[]` — список (сразу в памяти), `{}` со `:` — словарь, `{}`
без `:` — множество, `()` — **ленивый генератор**. Comprehension читаемее цикла,
когда задача — «преобразовать/отфильтровать итерируемое в коллекцию», и обычно
**чуть быстрее** ручного цикла (оптимизирован в CPython).

**Аналогия.** Comprehension — это конвейерная формула «возьми каждый элемент →
преобразуй → собери в коробку». Вместо того чтобы вручную доставать, обрабатывать
и класть по одному (цикл), вы описываете правило целиком одной строкой.

## Условия и вложенность

Comprehension поддерживает **фильтрацию** (`if` в конце) и **вложенные циклы**:

```python
# фильтр: только чётные (if в КОНЦЕ — это фильтрация)
evens = [x for x in nums if x % 2 == 0]

# тернарное выражение в начале — это ПРЕОБРАЗОВАНИЕ (не фильтр)
labels = ["even" if x % 2 == 0 else "odd" for x in nums]

# вложенные циклы: левый цикл — внешний (как в обычном for)
pairs = [(i, j) for i in range(3) for j in range(3)]   # 9 пар

# разворот матрицы (flatten)
flat = [x for row in matrix for x in row]              # порядок как в обычных for
```

Критичная тонкость, которую путают: **`if` в конце — это фильтр** (пропустить
элементы), а **`if/else` в начале — это тернарное выражение** (преобразовать
каждый, ничего не отбрасывая). Их синтаксические позиции разные. Вложенные циклы
читаются **слева направо**, как обычные `for` друг в друге.

**Аналогия.** `if` в конце — это сито на выходе конвейера (что-то отсеивается);
`if/else` в начале — это станок, который каждую деталь обрабатывает по-разному, но
пропускает все. Вложенные циклы — конвейер с конвейером: для каждой детали с первого
гоняем весь второй.

## Когда comprehension, а когда нет

Comprehension мощный, но им **легко злоупотребить**. Правила хорошего тона:

- **Простое преобразование/фильтрация** → comprehension (читаемо).
- **Большие/бесконечные данные** → **генераторное выражение** `(...)`, а не список
  — экономит память (см. урок про генераторы).
- **Сложная логика, несколько условий, побочные эффекты** → **обычный цикл**.
  Двух-трёхэтажный comprehension с вложенностью и фильтрами читать **тяжелее**, чем
  цикл — питоничность в ясности, а не в «уместить в одну строку».
- **Не для побочных эффектов**: `[print(x) for x in items]` — антипаттерн (строим
  список `None` ради печати); для действий нужен обычный `for`.

```python
# плохо: нечитаемый «однострочник»
result = [transform(x) for sub in data for x in sub if cond1(x) if cond2(x)]

# лучше: обычный цикл, когда логика сложная
result = []
for sub in data:
    for x in sub:
        if cond1(x) and cond2(x):
            result.append(transform(x))
```

Сравнение с `map`/`filter`: comprehension обычно **читаемее**, чем `map(f,
filter(pred, xs))`, и в современном Python предпочитают именно его. Главный тезис
для собеседования: comprehension — для **простых** преобразований; усложнилось —
вернись к циклу или генератору.

**Аналогия.** Comprehension — как хороший слоган: одна ёмкая строка лучше абзаца.
Но впихивать в слоган целую инструкцию — получится нечитаемая каша; тогда честный
абзац (цикл) понятнее.

## Памятка для собеседования

- **Comprehension** строит коллекцию из итерируемого в одном выражении (заменяет
  цикл с `append`): `[...]` список, `{k: v ...}` словарь, `{...}` множество, `(...)`
  **ленивый генератор**. Чуть быстрее ручного цикла.
- **`if` в конце — фильтр** (отсеивает); **`if/else` в начале — тернарное
  преобразование** (не отсеивает). Вложенные циклы читаются слева направо (внешний
  первым).
- Большие/бесконечные данные → **генераторное выражение** (память). Сложная логика/
  побочные эффекты → **обычный цикл**. Не строить список ради side-effect.
- Comprehension обычно читаемее `map`/`filter`.

## Частые ошибки в ответах

- Путать позицию `if`: фильтр (в конце) vs тернарник `if/else` (в начале).
- Неверно читать порядок вложенных циклов (внешний — левый `for`).
- Городить нечитаемые многоэтажные comprehension вместо цикла «ради одной строки».
- Использовать list comprehension для побочных эффектов или там, где нужен ленивый
  генератор (память).
