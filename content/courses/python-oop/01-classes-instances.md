# Классы и экземпляры

> Цель урока: понять разницу между атрибутами класса и экземпляра (источник
> коварных багов), роль `self`, и чем `__new__` отличается от `__init__`. Это
> фундамент ООП в Python, на котором строится всё остальное, и частая тема
> «почему все экземпляры видят одно значение».

## Атрибуты класса против атрибутов экземпляра

У атрибутов два уровня хранения:

- **Атрибут класса** определён в теле класса и **общий для всех экземпляров** —
  он хранится один раз в самом классе.
- **Атрибут экземпляра** создаётся через `self.x = ...` (обычно в `__init__`) и
  **свой у каждого объекта**.

При чтении `obj.x` Python ищет сначала в экземпляре, потом в классе. Самая частая
ловушка — **изменяемый атрибут класса**, который случайно делят все экземпляры:

```python
class Dog:
    tricks = []                  # атрибут КЛАССА — общий!
    def __init__(self, name):
        self.name = name         # атрибут экземпляра — свой

a, b = Dog("Rex"), Dog("Bo")
a.tricks.append("sit")
print(b.tricks)                  # ['sit'] — общий список, баг!
```

Правильно — изменяемое состояние создавать в `__init__` как атрибут экземпляра
(`self.tricks = []`). Атрибуты класса хороши для **констант** и **значений по
умолчанию** (неизменяемых), общих для всех.

**Аналогия.** Атрибут класса — это доска объявлений в подъезде (одна на всех),
атрибут экземпляра — личный блокнот жильца. Если завести «общий список дел» на
доске, записи одного жильца увидят все.

## self и связанные методы

`self` — это **первый параметр методов**, в который Python автоматически передаёт
сам экземпляр при вызове `obj.method()`. Он не ключевое слово, а соглашение
(можно назвать иначе, но не нужно). Когда вы пишете `obj.method(arg)`, Python
превращает это в `Class.method(obj, arg)` — `obj` становится `self`.

```python
class Counter:
    def __init__(self):
        self.value = 0
    def increment(self):         # self — это конкретный объект
        self.value += 1

c = Counter()
c.increment()                    # эквивалент Counter.increment(c)
```

Метод, доступный через экземпляр (`c.increment`), называется **связанным
(bound)** — он «помнит» свой объект и подставляет его как `self`. Через класс
(`Counter.increment`) метод **несвязанный** — это обычная функция, которой нужно
передать экземпляр явно. Понимание этого объясняет, зачем нужен `self` и как
работают `classmethod`/`staticmethod`.

**Аналогия.** `self` — это «я» в речи сотрудника. Когда конкретный сотрудник
(объект) говорит «я обновляю счёт», понятно, чей счёт. Связанный метод — сотрудник
уже знает, что «я» — это он; несвязанный — инструкция «пусть кто-то обновит счёт»,
которой надо указать, кто именно.

## __init__ против __new__

Два «конструктора», и их путают:

- **`__new__(cls, ...)`** — **создаёт** и возвращает новый объект (выделяет
  память). Вызывается первым, до `__init__`. Это статический метод, принимает
  класс `cls`.
- **`__init__(self, ...)`** — **инициализирует** уже созданный объект (заполняет
  атрибуты). Ничего не возвращает (`None`).

В 99% случаев вы пишете только `__init__` — `__new__` наследуется от `object` и
работает сам. `__new__` переопределяют редко, в особых случаях: создание
**неизменяемых** типов (наследники `int`, `str`, `tuple` — их значение нужно
задать при создании), реализация **синглтона** или кэширования экземпляров,
метаклассы.

```python
class Singleton:
    _instance = None
    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance      # всегда один и тот же объект
```

**Аналогия.** `__new__` — это отлить деталь из формы (создать заготовку),
`__init__` — настроить и собрать уже отлитую деталь. Обычно форма стандартная (её
не трогают), а вы только настраиваете готовую заготовку.

## Памятка для собеседования

- **Атрибут класса** — общий для всех экземпляров (хранится в классе); **атрибут
  экземпляра** (`self.x`) — свой у каждого. Чтение: экземпляр → класс.
- Ловушка: **изменяемый атрибут класса** делится всеми; изменяемое состояние
  заводить в `__init__` (`self.x = []`). Атрибуты класса — для констант/дефолтов.
- `self` — автоматически передаваемый экземпляр; `obj.m()` = `Class.m(obj)`.
  Связанный метод помнит объект, несвязанный требует его явно.
- `__new__` **создаёт** объект (до `__init__`, принимает `cls`); `__init__`
  **инициализирует** (принимает `self`, возвращает None). Обычно пишут только
  `__init__`; `__new__` — для неизменяемых типов, синглтонов, метаклассов.

## Частые ошибки в ответах

- Класть изменяемый объект в атрибут класса и удивляться, что он общий.
- Думать, что `self` — ключевое слово (это соглашение об имени первого параметра).
- Путать `__new__` и `__init__` или считать, что `__init__` создаёт объект (он
  инициализирует уже созданный).
- Возвращать значение из `__init__` (должен возвращать None).
