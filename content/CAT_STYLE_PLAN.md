# План: новые скины, шляпки и ачивки для котика

Ветка: `feature/cat-skins-hats`. Статус: **план утверждается** (реализация по спринтам, после каждого — проверка и стоп до команды).

## Что есть сейчас

- Скин = палитра одного 12×12 спрайта (`frontend/src/cat/CatSprite.tsx`, `PALETTES`):
  5 цветов (B/D/L/P/eye/mouth) на скин; тест `CatSprite.test.ts` гарантирует
  контраст глаза с мордой для **каждой** записи `PALETTES` — новые скины
  покрываются автоматически.
- Анлок по `best_streak` (`frontend/src/lib/cat.ts:SKIN_MILESTONES`): classic 0,
  tabby 3, tuxedo 7, calico 14, void 30. `resolveSkin` клампит выбор к открытым.
- Шляпа волшебника — жёстко от `stage === "wizard"` (стрик ≥ 14), пиксели
  захардкожены в `CatSprite`.
- Сервер: `pet_states.skin` — строка `String(20)` без enum-валидации
  (`backend/app/models.py:341`), PATCH `/api/pet`. Ачивок нет.

## Дизайн

### 1. Пять новых скинов (только палитры — ноль новых спрайтов)

| Скин | Идея | Палитра (B / D / L / P / eye) | Анлок (best_streak) |
|---|---|---|---|
| `sakura` | розовая нежность | #f2b8c6 / #8a4a5e / #ffe9ef / #e87a9a / #5e2a3a | 5 |
| `mint` | мятная свежесть | #8fd8c8 / #2f6b5e / #eafff8 / #f0a0a0 / #234f45 | 10 |
| `snow` | белоснежный, голубые глаза | #f5f5f7 / #9aa4b5 / #ffffff / #f2b8c0 / #4a90d9 | 21 |
| `ember` | тлеющий уголёк | #5a3230 / #2a1512 / #f0c090 / #e06040 / #7a2e12 | 45 |
| `golden` | легендарный золотой | #e8c352 / #8a6a1f / #fff3cf / #e89a6a / #6b4a10 | 60 |

Точные значения тюнингуются при реализации под тест контраста. Имена ru/en в
`locales`. Итоговая лестница: 0/3/5/7/10/14/21/30/45/60 — есть куда расти.

### 2. Пять шляпок — новое измерение кастомизации

Новый тип `CatHat = "none" | "wizard" | "grad" | "crown" | "flower" | "beanie" | "headphones"`.

| Шляпка | Идея | Анлок |
|---|---|---|
| `flower` цветочек за ушком | милота | 5 |
| `beanie` вязаная шапочка с помпоном | уют | 7 |
| `grad` академическая (выпускник) | тема подготовки к собесам | 14 |
| `crown` корона | статус | 30 |
| `headphones` наушники | лоуфай-кот | 45 |

- Рефакторинг: пиксели шляпы волшебника выносятся в реестр `HATS`
  (`{ hat: список пиксель-ректов }`) в `CatSprite.tsx`; рендер один для всех.
- **Совместимость**: `wizard` остаётся шляпой стадии — если пользователь не
  выбирал шляпу (`hat = null`), на стадии wizard показывается волшебная, как
  сейчас. Явный выбор (включая «без шляпы») перекрывает.
- Пикер шляпок в `PetSettings` — тот же UI-паттерн, что пикер скинов.
- `resolveHat` — кламп к открытым, зеркально `resolveSkin`.

### 3. Сервер: поле `hat` (безопасно для данных!)

- `PetState.hat: str | None` (`String(20)`, default NULL) + `hat` в
  `PetStateOut`/`PetStateUpdate` + прокидка в PATCH-сервисе.
- **Миграция без пересоздания БД**: идемпотентный шаг в `init_db()` —
  `PRAGMA table_info(pet_states)` → если колонки нет, `ALTER TABLE … ADD COLUMN
  hat VARCHAR(20)`. SQLite это поддерживает; существующий `data/app.db` и
  docker-volume НЕ трогаются, данные пользователей сохраняются.
- Тест: PATCH `{hat: "crown"}` → сохранилось; проверка идемпотентности init.

### 4. Ачивки по стрику заходов

- **Ноль бэкенда**: всё выводится из `best_streak`, который уже хранится и
  приходит в `GET /api/pet`.
- `ACHIEVEMENTS` в `lib/cat.ts`: пороги 1/3/5/7/10/14/21/30/45/60/100, у каждой
  id, эмодзи-иконка или мини-спрайт (открываемый скин/шляпка = иконка), название
  и подпись ru/en (напр. 7 — «Неделя без пропусков», 14 — «Котик стал магом»,
  100 — «Сотка»).
- Панель «Достижения» в настройках питомца (`PetSettings`): сетка карточек,
  открытые цветные, закрытые серые с порогом; прогресс «X из N».
- Тост при новом анлоке: `useCat` сравнивает старый/новый `best_streak` после
  визита и показывает `useToast().success(...)` (+ упоминание, если открылся
  скин/шляпка).
- Чистые функции (`achievementsUnlocked`, `newlyUnlocked`) — vitest.

## Спринты

Дисциплина прежняя: после каждого спринта — тесты + typecheck + ручная
верификация + отчёт, затем **стоп до команды**.

### Спринт 1 — скины + ачивки (чистый фронтенд)
1. 5 палитр в `PALETTES`, майлстоуны в `SKIN_MILESTONES`, имена ru/en.
2. `ACHIEVEMENTS` + чистые функции + vitest; панель достижений в PetSettings;
   тост при анлоке.
3. Верификация: vitest (контраст-тест покроет палитры), tsc, превью всех скинов
   в браузере (светлая/тёмная тема). Коммит. ⏸ СТОП.

### Спринт 2 — шляпки (фронтенд + маленький бэкенд)
1. Бэкенд: колонка `hat` + идемпотентный ALTER в `init_db` + схемы + тесты
   (pytest, включая «старая БД без колонки поднимается без потерь»).
2. Фронтенд: реестр `HATS` (5 новых + рефактор wizard), `HAT_MILESTONES`,
   `resolveHat`, пикер в PetSettings, ru/en.
3. Верификация: pytest + vitest + tsc + превью каждой шляпки на каждой стадии;
   проверка на реальной локальной БД, что данные целы. Коммит. ⏸ СТОП.

### Спринт 3 — полировка и интеграция
1. QA: комбинации скин×шляпка×настроение×стадия, reduced-motion, мобильный
   размер виджета; тюнинг палитр/пикселей по глазам.
2. Полные прогоны (pytest 145+, vitest, build), обновление CLAUDE.md.
3. ⏸ СТОП → merge в `master` только по команде (данные в БД не участвуют в
   merge; перед деплоем — обычный бэкап).

## Риски

- SQLite ALTER TABLE — единственное касание живой БД; шаг идемпотентный и
  аддитивный (NULL-колонка), бэкап перед мержем как обычно.
- Контраст новых палитр в тёмной теме — проверяется существующим тестом + глазами.
- Клиенты со старым кэшем пришлют PATCH без `hat` — поле опциональное, ок.
