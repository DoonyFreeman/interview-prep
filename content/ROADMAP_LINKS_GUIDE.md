# Кураторство ссылок роудмапа — runbook

Инструкция для агента, заполняющего внешние ресурсы одного или нескольких
курсов в `content/roadmap.json`. Самодостаточна: всё нужное — здесь и в
`content/courses/<slug>/metadata.json` (список уроков курса).

## Что заполнять

Для каждого назначенного курса:

- **`resources` курса** — 2–4 ссылки, покрывающие тему курса целиком:
  1–2 видео + 1–2 статьи/доки. Это fallback: их увидит каждый урок курса,
  у которого нет собственных ссылок.
- **`lesson_resources`** — только для уроков, где есть **точный сильный матч**
  (видео/статья ровно про тему урока). Без филлера: нет точного матча — ключ
  урока не создаётся, урок унаследует ресурсы курса. 1–2 видео + 1–2 статьи
  на урок максимум.

Формат ресурса (все поля обязательны):

```json
{ "type": "video",            // video | article | docs
  "lang": "ru",               // ru | en
  "title": "Как устроен GIL", // человекочитаемое название (без имени канала)
  "url": "https://www.youtube.com/watch?v=…",
  "source": "Диджитализируй" } // канал / сайт / автор
```

## Правила отбора

1. **RU-приоритет.** Английское — только когда русского достойного нет или
   оно заметно слабее; помечать `"lang": "en"`.
2. **Качество > количество.** Уровень — middle-собеседование: глубокие
   разборы, а не «первые шаги для чайников» (Гоша Дударь-стайл «за 10 минут» —
   нет). Актуальность: Python 3.10+, современные версии инструментов.
3. **Каждый URL проверить на живость** (см. ниже). Непроверенное не сдавать.
4. Никаких пейволлов, сокращалок, реферальных хвостов, логин-only контента.
   UTM-параметры срезать. Плейлисты YouTube допустимы (для курс-уровня).
5. `docs` — официальная документация (docs.python.org, fastapi.tiangolo.com,
   redis.io, kafka.apache.org, nginx.org, postgresql.org …). RU-версии доков —
   если официальные.
6. Дубли: одна и та же ссылка не должна повторяться внутри курса (на курс- и
   урок-уровне одновременно).

## Как проверять живость

- **YouTube** (видео и плейлисты): `GET
  https://www.youtube.com/oembed?url=<video_url>&format=json` — HTTP 200 =
  живое (в ответе будет title — сверь, что это то видео), 401 = живое, но
  embed запрещён (нам ок — мы ссылаемся), 404/400 = мертво/приватно →
  выбросить.
- **Прочее**: HTTP-запрос с браузерным User-Agent; 200 = ок; 403 у
  Хабра/Cloudflare допустим, если URL получен из результатов поиска (боты
  режутся, ссылка живая); 404/410 → выбросить.
- Заголовок/тайтл из проверки должен соответствовать заявленному `title`
  ресурса — не сдавать ссылку «вслепую» по сниппету поиска.

## Формат сдачи

Строго один JSON-блок (без комментариев), ключ — slug курса:

```json
{
  "python-core": {
    "resources": [ {…}, {…} ],
    "lesson_resources": {
      "gil": [ {…} ]
    }
  }
}
```

Слаги уроков — только из `metadata.json` курса. После сдачи ссылки прогоняются
`scripts/check_roadmap_links.py` и integrity-тестами (`pytest
tests/test_content_integrity.py`). Минимум на курс: **≥2 ресурса**, из них
хотя бы один «смотреть-или-читать авторитетно» (видео **или** офиц. доки) и
хотя бы один «почитать» (статья **или** доки). Видео желательно у каждого
курса, но если сильного RU-видео по теме нет — **не ставим филлер**, курс
опирается на официальные доки + разбор-статью.
