# Spec Delta

## Purpose

Библиотека позволяет скачивать общие учебные PDF, а владельцу привязанного аккаунта — отдельные личные материалы и персональный сборник.

## ADDED Requirements

### Requirement: Личные кнопки в каталоге
Страница `/cheatsheets` SHALL показывать кнопки «Скачать OpenSpec PDF» и «Скачать мой полный набор» только привязанному аккаунту владельца при доступности соответствующих файлов. Кнопки SHALL использовать штатный стиль каталога.

#### Scenario: Каталог владельца
- **WHEN** владелец входит с привязанной сессией и открывает каталог при наличии обоих файлов
- **THEN** рядом с общим скачиванием видны обе личные кнопки, без обрезки на мобильном и настольном экранах в обеих темах

#### Scenario: Каталог другого аккаунта
- **WHEN** каталог открывает другой аккаунт, в том числе с тем же отображаемым именем
- **THEN** личных кнопок нет, общие действия остаются доступны как прежде

### Requirement: Серверный доступ только владельцу
Сервер MUST проверять привязку владельца при каждом запросе статуса доступности и скачивания. Личные PDF MUST NOT отдаваться статически или кэшироваться; отсутствие или несоответствие привязки либо файла не должно раскрывать содержимое и детали хранения.

#### Scenario: Прямое обращение без доступа
- **WHEN** анонимный запрос, другой аккаунт или непривязанная сессия обращается напрямую к защищённой загрузке
- **THEN** сервер не возвращает PDF; другой аккаунт и непривязанная сессия получают такой же результат, как при отсутствии файла

#### Scenario: Артефакт не готов
- **WHEN** владельцу не подготовлен один из двух файлов или его целостность не подтверждена
- **THEN** это скачивание недоступно, а второе остаётся доступным, если оно корректно подготовлено

#### Scenario: Некорректный хеш одного файла
- **WHEN** манифест привязан к владельцу, но у одного файла неверный формат или значение хеша, либо неверен хеш общего PDF, от которого зависит сборник
- **THEN** недоступны только затронутые кнопка и прямое скачивание; другой файл с корректной проверкой по-прежнему скачивается

### Requirement: Исходный OpenSpec PDF
Отдельная личная кнопка SHALL скачивать исходный шестистраничный PDF без изменений как вложение с типом `application/pdf`.

#### Scenario: Скачивание владельцем
- **WHEN** привязанный владелец нажимает «Скачать OpenSpec PDF»
- **THEN** сохраняется файл из шести страниц, байты которого совпадают с исходным вложением, с политикой `private, no-store`

#### Scenario: PDF не проходит проверку перед размещением
- **WHEN** офлайн-проверка обнаруживает активное действие, в том числе в закладке, или не может проверить структуру исходника
- **THEN** исходник не допускается к размещению и не используется для сборки; существующие файлы не заменяются

### Requirement: Персональный сборник
Личный полный набор SHALL сохранять весь действующий общий сборник без Python и добавлять шесть страниц OpenSpec ровно один раз с отдельной закладкой. Публичные общий и RAG PDF MUST оставаться неизменными.

#### Scenario: Скачивание личного набора
- **WHEN** привязанный владелец нажимает «Скачать мой полный набор»
- **THEN** скачивается PDF на шесть страниц больше общего сборника, а закладка OpenSpec ведёт на первую страницу добавленного материала

#### Scenario: Скачивание общих материалов
- **WHEN** любой пользователь использует исходные общие ссылки
- **THEN** скачиваются прежние общий и RAG PDF без личного материала и без перехода на защищённую загрузку
