# Proposal

## Why

Владелец подтверждённого аккаунта хочет скачивать приложенную шестистраничную шпаргалку по OpenSpec и Agent Engineering со страницы шпаргалок отдельно и вместе с общим набором. PDF содержит личный материал и не должен становиться частью публичной библиотеки.

## What Changes

- Добавить на `/cheatsheets` две кнопки в стиле каталога, видимые только для привязанного аккаунта владельца: «Скачать OpenSpec PDF» и «Скачать мой полный набор».
- Первая кнопка скачивает исходный шестистраничный PDF. Вторая — отдельный персональный сборник из текущего общего набора плюс шесть страниц OpenSpec с отдельной закладкой. Python по-прежнему скачивается отдельно; на проверенной базе личный сборник — 25 страниц.
- Проверять доступ на сервере при каждом скачивании. Не включать приватные PDF и их содержимое в Git, статические файлы, сборку приложения или логи. Общий PDF и RAG-сборник не менять.

**Outcome Hypothesis:** Владелец скачивает каждый из двух вариантов одним нажатием; остальные пользователи не видят этих действий и не получают PDF даже по прямому URL.

**Вне scope:** публичная карточка и веб-ридер OpenSpec, обезличенная версия, изменение существующих сборников, индексация ассистентом и миграции БД.

## Capabilities

### New Capabilities

- `cheatsheet-library`: отдельный PDF и персональный сборник, доступные только привязанному аккаунту.

### Modified Capabilities

Нет.

## Impact

Страница каталога и RU/EN-строки, защищённые API выдачи PDF, приватные файлы на существующем серверном томе, офлайн-сборка персонального PDF и тесты. Отдельный коммит и штатная выкатка после проверок и разрешения на внешние действия.
